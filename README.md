A short poem about agency — the power to choose and to act — on two agents
agreeing on one plan. An entry for the [make.fun](https://make.fun) bounty
[the-poem-about-two-agents-20261121-1441](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

## How it works

`main.ts` (Node 22) writes the poem to `/output/entry.txt` (1–280
characters, UTF-8). Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
